# 平井 新 — 研究者個人サイト

東海大学政治経済学部政治学科 専任講師・平井新の個人サイト。GitHub Pages で公開しています。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | サイト本体。CSS・JavaScript はすべてこの1ファイルに含まれています |
| `portrait.jpg` | プロフィール写真（560×560） |
| `.nojekyll` | GitHub Pages の Jekyll 処理を無効化 |

外部ライブラリは使っていません。フォントは各OSの標準搭載書体（日本語は明朝体、欧文はセリフ体）を指定しています。

## 直したいときは

`index.html` をテキストエディタで開いて編集します。よく触る箇所は次のとおりです。

- **お知らせ** — `<section id="news">` の中。`news-item` を1つコピーして日付と本文を書き換えれば追加できます
- **業績を足す** — `<section id="articles">` などの中の `entry` を1つコピーして書き換えます
- **日本語と英語** — `<span class="ja">…</span>` が日本語、`<span class="en">…</span>` が英語です。両方書き換えてください
- **DOIリンク** — `<a class="doi" href="https://doi.org/…">DOI</a>` の形で追加します

編集して `git push` すると、1分ほどで公開サイトに反映されます。

## ローカルで確認する

```
python3 -m http.server 8000
```

を実行して `http://localhost:8000/` を開きます。ファイルを直接ダブルクリックして開いても表示できます。
